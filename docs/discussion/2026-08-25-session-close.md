## Three checks now exist, and why

`make check` runs all of them. Each guards a rule that decayed the moment
nothing failed when it was broken - the same argument as `check-seam`, which
has held since day one for exactly that reason.

- **`check-register.py`** - the register grew 418 to 992 lines in three days and
  never once shrank, because resolutions were appended rather than substituted.
- **`check-corefacts.py`** - ADR-0015's aspect table silently became a
  description of software nobody runs when the cores were swapped.
- **`micprobe.sh`** - not in `make check` (it needs the device), but it turns
  "does this sound right" into a number.

## The pattern behind most of today's lost time

Every expensive mistake was the same shape: **a claim nobody could check.**

- The register drifted because nothing failed when it did.
- ADR-0015's table aged because a measurement was keyed to a *system* rather
  than to the *binary* that produced it.
- An audio evening went into a fault that did not exist, because "is there
  sound" was treated as a question only a human could answer, when "how loud"
  is a number and `arecord` was on the device the whole time.
- A careful hand audit still got three of five cores wrong, because it measured
  a staging directory that had drifted. **Carefulness cannot verify a hash.**

The instruments written today - `mixprobe`, `dispprobe`, `micprobe`,
`--tap-audio` - all exist to answer a question before code depends on the
answer. That is the habit worth carrying, not any of the specific findings.

## Device facts that cost real time

- **`digital volume` is INVERTED.** 0 is loudest, 63 silent, while the driver
  advertises `step=+1.16dB`. Trusting that metadata meant every "louder" was
  quieter, and 63 - set as "maximum" - is silence.
- **`Headphone Volume` is not a speaker level.** Raising it routes to the jack
  and mutes the speakers. The firmware zeroes it deliberately.
- **`digital volume` has no mute point** (`mute=0`); its minimum is about
  -74 dB. True silence needs `HpSpeaker Switch`.
- **L2/R2 are `ABS_Z`/`ABS_RZ`**, not keys. Absence from a KEY mask is not
  absence of a button.
- **`gpio243` is the physical switch.** Unclaimed, debounced, interrupt-capable,
  and reserved for the launcher.

## Open, in rough order of value

1. **Launcher/host shared state.** Three things now want the same channel: a
   remap table, `SET_INPUT_DESCRIPTORS` labels, and volume/brightness levels.
   Worth one design pass rather than three bolted-on messages.
2. **Headless conformance test** (§13), which closes both of §11's items - the
   RSS budget and no-malloc-in-frame-loop are both unproven, and §11 is titled
   "the project's thesis". It is also the general form of today's lesson.
3. **`ADR-0011`'s locked rect** assumes base geometry is representative, and for
   the Sega cores it is not. `[LB]`, and wrong in three of seven display modes.
4. **Saves do not transfer between cores** for the same game - 16 KB vs 64 KB of
   SRAM for Herzog Zwei depending on the core.
